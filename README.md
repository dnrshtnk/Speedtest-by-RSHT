# Speedtest by RSHT

Лёгкий `sh`-скрипт для проверки исходящего интернет-соединения VPS, сервера или ноды. Измеряет HTTP-задержку, скорость скачивания и загрузки до ближайшей точки сети Cloudflare. Ничего устанавливать через `pip` или `npm` не нужно.

## Требования

- POSIX-совместимая оболочка (`sh`)
- `curl` и `awk`
- `mktemp` для проверки загрузки

## Запуск

Склонируйте репозиторий и запустите скрипт:

```sh
git clone https://github.com/dnrshtnk/Speedtest-by-RSHT.git
cd Speedtest-by-RSHT
sh speedtest.sh
```

Также можно скачать один файл `speedtest.sh` и запустить его командой `sh speedtest.sh`. Скрипт не требует прав root.

По умолчанию выполняются три небольших запроса для задержки и по два переноса файла размером 5 MiB в каждом направлении. Общий тестовый трафик — около **20 MiB**.

```sh
sh speedtest.sh --size 10 --runs 3   # около 60 MiB трафика
sh speedtest.sh --download-only      # только скачивание
sh speedtest.sh --upload-only        # только загрузка
sh speedtest.sh -4                   # принудительно IPv4
sh speedtest.sh -6                   # принудительно IPv6
sh speedtest.sh --help
```

`--size` принимает от 1 до 100 MiB на перенос, `--runs` — от 1 до 5 прогонов на направление.

Пример вывода:

```text
Target: Cloudflare (https://speed.cloudflare.com)
Payload: 5 MiB x 2 run(s) per direction
HTTP latency: 18.4 ms (3-request average)
Download: 94.21 Mbps (2-run average)
Upload: 47.63 Mbps (2-run average)
```

## Что означают результаты

Скорость указана в **Mbps** (мегабитах в секунду). Это среднее по прогонам в каждом направлении. Задержка — время до первого байта HTTP-ответа, поэтому она включает DNS, установку соединения, TLS и обработку запроса. Это **не ICMP ping**.

Скрипт проверяет маршрут от машины, на которой он запущен, до Cloudflare. Он не измеряет пропускную способность между двумя вашими нодами, скорость диска или производительность сайта. На результат влияют маршрут, загруженность сети, ограничения провайдера и длительность короткого теста. Для более устойчивой оценки увеличьте размер и число прогонов.

Для теста используются [публичные эндпоинты Cloudflare Speedtest](https://github.com/cloudflare/speedtest). При их недоступности или блокировке скрипт завершится с ошибкой. Cloudflare сообщает, что собирает результаты тестов для агрегированной аналитики.
